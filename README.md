I'm a C++ developer based in Madrid, Spain. Most of my work revolves around Windows internals, reverse engineering, and low-level programming.

I like understanding how things work under the hood, whether it's the operating system, a compiled binary, or the app I'm building. My repositories include research projects, small experiments, and complete applications.

### What I work on

- **Windows internals**: kernel research, driver development, and OS structures.
- **Reverse engineering**: understanding compiled code and Windows behavior.
- **Systems programming**: x64 memory management, PE internals, and kernel ↔ user-mode communication.
- **Application development**: native C++ applications, with backend and web work alongside them.
